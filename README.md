# User Search App

A simple web application that allows users to search for user details by entering a User ID.

## Features

- Search users by ID
- Displays user name
- Displays username
- Displays email
- Displays city
- Input validation
- Error handling
- API data fetching

## Technologies Used

- HTML
- CSS
- JavaScript
- DOM Manipulation
- Fetch API
- Async/Await
- JSON
- Try/Catch

## API Used

JSONPlaceholder

## How It Works

1. Enter a User ID between 1 and 10.
2. Click the Search button.
3. The application fetches the user data from the API.
4. The user's name, username, email and city are displayed.

## Learning Outcome

This project helped me practice DOM manipulation, event handling,
Fetch API, JSON, async/await, input validation and error handling.
